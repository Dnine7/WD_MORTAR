# Third-party notices for the portable OCR runtime

The portable build includes selected Windows x64 files from
RapidOCR-json v0.2.0. They are extracted into the user's local application
cache on first launch and are used only for offline coordinate recognition.

- RapidOCR-json: MIT, https://github.com/hiroi-sora/RapidOCR-json
- RapidOcrOnnx: Apache-2.0, https://github.com/RapidAI/RapidOcrOnnx
- PaddleOCR models: Apache-2.0, https://github.com/PaddlePaddle/PaddleOCR
- ONNX Runtime: MIT, https://github.com/microsoft/onnxruntime

The upstream source archive is:
